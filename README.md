# Faraday — instaladores e atualizações

Aqui ficam só os arquivos de cada versão do Faraday (assistente de reuniões e ditado para Windows).

1. Abra a [última versão](../../releases/latest).
2. Baixe **Instalar.Faraday.exe** e abra.

O instalador baixa o programa, confere o SHA-256 e instala sem administrador. O próprio Faraday avisa quando sai versão nova.
